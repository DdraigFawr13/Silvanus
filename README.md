# Silvanus

A fantasy frontier-town management idle sim for an Android phone, built as a PWA. The town stands under a Crown writ at the edge of a deep forest that is rich in magical resources and full of monsters.

- Design and scope: [docs/CHARTER.md](docs/CHARTER.md)
- Current state and next step: [docs/HANDOFF.md](docs/HANDOFF.md)
- Settled decisions: [docs/DECISIONS.md](docs/DECISIONS.md)

M1 Town is built and deployed at https://silvanus-xi.vercel.app, from [docs/specs/m1-town.md](docs/specs/m1-town.md). The current step is in [docs/HANDOFF.md](docs/HANDOFF.md).
